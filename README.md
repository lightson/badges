# Podcast Badges by Podlink

While building [Podlink](https://pod.link), I’ve spent an inordinate amount of time collecting and optimizing high quality versions of every podcast app icon I could find, often redrawing raster images as SVGs. After seeing my distinctive versions crop up here and there, I've decided to publish my full collection as **Podcast Badges by Podlink**. Please refer to the linked guidelines (when available) for official badges and usage guidelines.

> [!IMPORTANT]  
> All trademarks are the property of their respective owners. This collection is provided for educational and promotional use only.
